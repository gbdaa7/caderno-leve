Was diese Website erhebt

Diese Website erhebt keine personenbezogenen Daten: Es gibt keine Registrierung, kein Formular, keine Kommentare und keinen Login. Die Website setzt keine Cookies und nutzt keine Analyse-Tools, Werbe-Pixel oder andere Tracker von Dritten.

Parameter von Werbekampagnen

Wenn Sie über eine Anzeige kommen, kann die Adresse Kampagnenparameter enthalten (z. B. utm_source oder Klick-Kennungen). Damit wir wissen, von welcher Anzeige ein Kauf stammt, speichert die Website diese Parameter vorübergehend im Sitzungsspeicher Ihres Browser-Tabs (sessionStorage), der beim Schließen des Tabs gelöscht wird, und hängt sie an den Kiwify-Kauflink an. Das ist kein Cookie, und diese Website sendet es nicht an uns.
