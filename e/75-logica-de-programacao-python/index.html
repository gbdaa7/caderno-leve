Sempre quis aprender a programar, mas achou difícil? Comece pela lógica, com exemplos simples.

O Lógica de Programação com Python ensina, do zero, a pensar em passos e escrever programas em Python 3.

Cada capítulo tem exemplos para digitar e entender: variáveis, operações, if, for, while, listas, funções, dicionários, tratamento de erros e um projeto final de controle de gastos.
